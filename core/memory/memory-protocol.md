## Memoria
Si hay herramienta de memoria (Engram): al empezar, recupera por proyecto y tema antes de preguntar al usuario. Guarda tras decisiones, descubrimientos, bugs resueltos y convenciones (tipo, título, contenido breve, por qué, archivos). Sin secretos ni datos personales. La memoria nunca sustituye la verificación: si contradice al código, gana el código y corriges la memoria.
